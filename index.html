Pitch — quantized sample & hold

Plays a short repeating motif that follows a melodic contour: mostly steps between neighbouring notes, with the occasional leap that steps back the other way. The first pass states it cleanly, then Pitch evolution mutates it a little each time round. Note lengths and rests come from the rhythm engine below.

Rhythm engine

Each slot in the motif gets a note length (or a rest) from the values you enable below. Rhythm evolution sets how often a slot is re-rolled on later passes.

staticevolvingrandom

Vocal expression

Each slot in the motif gets an inflection from the ones you tick below, the same way it gets a note length. Expression evolution sets how often a slot's inflection changes on later passes.

staticevolvingrandom

Filter envelope

A filter over the whole choir output, swept by its own envelope on every note.

Vowel — quantized sample & hold

Each step holds a position along the vowel space (a → e → i → o → u). In note-synced mode the sequence advances on note onsets, so each note is a syllable.
